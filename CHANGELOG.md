# Changelog

## 1.1.0

- Added variable-width pulse oscillators and PWM depth/rate controls.
- Added 1–6 unison layers with detune, stereo spread, and gain compensation.
- Added mono last-note priority, legato/retrigger envelopes, and timed portamento.
- Added sustain-aware mono key stacks and independent same-pitch input tokens.
- Made cutoff and resonance respond to held notes and release tails, with smoothing.
- Added six motion-bank presets, bringing the bank to 16 sounds.
- Added oscillator, unison, playing-mode, and glide controls to the demo.
- Adapted demo playback for mono presets and made manual playing stop the demo.
- Anchored pitch and envelope automation to note-event times for accurate glides and releases.
- Preserved the original ten presets and their single-layer signal path.
- Expanded documentation for parameters, mono scheduling, and CPU tradeoffs.

## 1.0.0

- Initial release with 10 original ’80s-inspired analog and FM patches.
- Reusable, dependency-free Web Audio engine with configurable polyphony.
- Stereo chorus, phaser, ping-pong delay, and generated convolution reverb.
- Mouse, touch, and computer-keyboard demo with sustain, pitch bend, and modulation.
- Arpeggiator, original demo sequence, live scope, and responsive interface.
